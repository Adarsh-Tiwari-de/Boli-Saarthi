# Decision Log

## ADR-001 — Keep marketplace publishing out of the first MVP
- **Status:** Proposed
- **Date:** 2026-10-29
- **Context:** Speech, multimodal AI, and marketplace integration can each consume significant time.
- **Decision:** Prove the core flow through a seller-confirmed saved draft before attempting live ONDC publishing.
- **Consequence:** UI must distinguish a confirmed draft from a published listing.
